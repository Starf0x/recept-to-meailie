Recipe to Mealie

Send any recipe page to Mealie with one click.

Connection

The part after /g/ in your Mealie address bar, e.g. /g/home/.
How do I get an API token?
  1. Log in to Mealie and click your name/avatar → Profile.
  2. Don't see API Tokens? Open Edit profile / User settings, enable Show advanced features and save.
  3. Open API Tokens, type a name (e.g. Browser extension) and click Generate.
  4. Copy the token right away (it's shown only once) and paste it above.
